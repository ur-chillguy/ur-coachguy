# ur.coachguy

Training planner (beta) untuk lari, sepeda, renang, dan triathlon. Jadwal disesuaikan setiap minggu dari hasil latihan yang dicatat.

- Halaman produk: `index.html`
- App: `app/index.html` (satu file, tanpa backend; data tersimpan di browser pengguna)
- PWA: `manifest.webmanifest`, `sw.js`, `icons/`

Dibuat oleh [@ur.chillguy](https://instagram.com/ur.chillguy).
